# Beyond Basics - Python Deep Dive

Welcome to the **Beyond Basics** section! This collection of guides is designed for curious students who want to understand how Python works under the hood and explore advanced topics that go beyond the standard curriculum.

## Topics

### 1. [Virtual Environments - Why They Matter](virtualenv_explained.md)
Learn why virtual environments are essential for Python development, how they work internally, and best practices for managing project dependencies.

### 2. [How pip install Works](pip_install_explained.md)
Understand the magic behind `pip install -r requirements.txt` - how Python packages are downloaded, installed, and how dependency resolution works.

### 3. [Packaging Tkinter Applications](tkinter_to_executable.md)
Step-by-step guide to converting your Tkinter GUI programs into standalone executable files that can run without Python installed.

### 4. [Working with Archives in Python](working_with_archives.md)
Master archive manipulation in Python - creating, extracting, and navigating archives with proper relative path handling to avoid security issues.

### 5. [Managing Windows Registry with Python](windows_registry_management.md)
Comprehensive guide to reading, writing, and managing the Windows Registry using Python's `winreg` module. Includes practical examples like controlling USB storage, managing application settings, boot mode configuration, and essential safety practices.

---

## How to Use This Section

Each guide is self-contained and can be read independently. However, they build on fundamental Python knowledge from the main course. If you encounter unfamiliar concepts, refer back to the main course materials.
